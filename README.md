# AE1 - Acceso a Base de Datos Relacionales mediante ORM (SQLAlchemy)

## 📋 Descripción

Actividad experimental (APE) de la Unidad 3: **Acceso a base de datos relacionales mediante Object Relational Mapper (ORM)**.

Se implementa un sistema de gestión para una red de **clínicas veterinarias** usando:
- **Python 3**
- **SQLAlchemy** (ORM)
- **SQLite** (base de datos)

El sistema modela clínicas, consultorios, veterinarios e historias clínicas, aplicando relaciones uno-a-muchos y realizando consultas con `all`, `filter`, `order_by`, `or` y `and`.
